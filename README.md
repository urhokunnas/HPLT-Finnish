The documents in this repository deal with the Finnish subset of HPLT 4.0, but the code can be used for any language or adjusted for use with other forms of data. There are more detailed readme files within each folder. 

The folder `code` contains Python code for filtering, sorting and analysing the HPLT 4.0 Finnish subset. 

The folder `counts` contains dictionaries revealing how many documents contain particular combinations of labels, allowing further analysis.

The folder `results` contains plots visualising data distribution as well as some numerical data further derived from the `counts` data.
